# Permitted `native_decide` uses, as `<count> <path>`.
#
# `native_decide` discharges a goal by compiling it and trusting the result,
# which attaches a per-theorem axiom:
#
#   'viaNative' depends on axioms: [propext, Quot.sound, viaNative._native.native_decide.ax_1_1]
#   'viaKernel' depends on axioms: [propext, Quot.sound]
#
# Everything that could reasonably be moved off it has been. Each entry below
# is a deliberate exception, not a leftover. The check treats these as a
# ceiling: counts may go down freely, but any increase, or any use in a file
# not listed here, fails CI.
#
# When a genuinely new exception is needed, add it here in the same commit and
# say why in the commit message.

# --- Cited pipeline shape theorems -------------------------------------------
# These run the compiler over a program and compare the result to a literal.
# Each is cited by a neighbouring proof via `rw [...]`, so the equation has to
# exist as a theorem; `#guard` cannot stand in. `decide`, `decide +kernel`,
# `simp` and `rfl` all get stuck -- the term needs more unfolding of
# `termination_by` recursion than the kernel will do.
5 Flapjack/Correctness.lean
3 Flapjack/Test/CorrectnessTarget.lean

# --- Named machine-execution theorems ----------------------------------------
# These execute a linked image on the RISC-V machine (`executeFunctionAt`,
# `executeFunctionAtWithFfi`). Machine execution is past what kernel reduction
# will unfold, so `native_decide` is required to state these results with a
# name at all.
3 Flapjack/Test/FullSsaPipeline.lean
3 Flapjack/RiscV/CorrectnessFfiMachine.lean
1 Flapjack/Test/CorrectnessFfi.lean

# --- Allocation over an expression program -----------------------------------
# `wordSsaRenameFunction` recurses into a `WordExp`, which neither the
# elaborator's `whnf` nor the kernel will unfold. Where the program is a bare
# `.move` there is no expression to recurse into and `decide +kernel` does get
# through, which is why only some allocator tests need this.
3 Flapjack/Test/AllocatorRegAlloc.lean

# --- Nested `have` inside a larger proof -------------------------------------
# Supplies a proof term to the surrounding proof, so `#guard` does not apply.
1 Flapjack/Test/AllocatorSpills.lean
